キー: Shift / Z=クラッチ(押している間踏む) / Space=アクセル / ↑↓・E・Q=シフト / 数字0-9=ギア直接 / N=ニュートラル / B=ニトロ / R=エンジン再始動
タッチ: 左のペダルをなぞって踏み込み量を調整(離すとゆっくり戻る) / 右=アクセル(下ほど深く) / ゲートをタップでシフト / 右上のNOSボタン=ニトロ(横画面推奨)
クラッチを踏まないとギアは入りません。ランプが青になってから発進、早いとフライングです。ウイリーしすぎるとひっくり返ります。
